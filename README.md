# AWS Learning Documentation

This repository documents my journey and hands-on practice with core AWS concepts, organized on a weekly basis. Each week focuses on specific AWS domains, from IAM and EC2 to storage, networking, load balancing, and monitoring. The accompanying shell scripts and notes are my own study materials, experiments, and summaries.

## Table of Contents

- [Overview](#overview)
- [Weekly Topics](#weekly-topics)

## Overview

This repo serves as a personal documentation and knowledge base for foundational AWS topics. The goal is to summarize, script, and share practical insights for future reference.

## Weekly Topics

| Week          | Topic                | Description                          |
|---------------|----------------------|--------------------------------------|
| **Week 7**    | IAM                  | Identity & Access Management basics, users, groups, policies. |
| **Week 8**    | EC2                  | Launching, configuring, and using Elastic Compute Cloud instances. |
| **Week 9**    | Storage              | Overview and use of S3, EBS, and elastic storage options. |
| **Week 10**   | Networking           | VPC fundamentals, subnets, security groups, and networking concepts. |
| **Week 11**   | Load Balancing       | Elastic Load Balancing (ELB), health checks, and scaling. |
| **Weeks 12-13**| Monitoring & Observability | Using AWS CloudWatch and related monitoring tools. |

## How to Use This Repo

- Each folder corresponds to a week’s topic and contains scripts and notes (`.sh` files).
- Feel free to explore, adapt, or extend the scripts for your own AWS practice.
- Prerequisite: AWS CLI configured and basic shell scripting knowledge.
